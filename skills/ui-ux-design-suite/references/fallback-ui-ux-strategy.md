# UX Strategy

## Goal
Turn a vague product/UI request into a design brief grounded in user outcome and product constraints.

## Resolve

- primary user and context;
- job-to-be-done;
- current pain or unmet need;
- primary outcome and observable success;
- task frequency/urgency;
- platform/device context;
- content/data characteristics;
- critical constraints;
- non-goals.

## Procedure

1. Infer from product evidence first.
2. Use the material-question gate for blocking unknowns.
3. Avoid creating features merely because similar products have them.
4. Define a minimum success condition before expanding scope.
5. Separate required capability from visual presentation.

## Output
A concise strategy brief another subskill can use without re-deciding the root goal.
