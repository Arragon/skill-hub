# Information Architecture

## Goals
Optimize findability, predictable grouping, stable mental models, clear labels, scalable additions, and minimal unnecessary depth.

## Procedure

1. Inspect current routes, labels, categories, and user expectations.
2. Inventory the information/actions the user must find.
3. Group by task/mental model rather than implementation ownership.
4. Preserve stable existing taxonomy when it already works.
5. Identify primary, secondary, contextual, and rare actions.
6. Test whether new items fit future additions without creating a parallel navigation system.
7. Check labels for ambiguity and duplication.

## Output
Provide the proposed hierarchy/navigation map plus rationale for changed placements.

## Prohibitions
Do not restyle the UI or move items merely to make the design look different.
