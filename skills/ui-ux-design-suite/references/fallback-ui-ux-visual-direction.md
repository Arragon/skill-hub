# Visual Direction

## Principle
Visual design should express product character and task priority, not generic trend-following.

## Inputs
Use approved structure, current brand/design constraints, content density, user frequency, platform, and accessibility requirements.

## Resolve

- visual tone/personality;
- density and whitespace strategy;
- hierarchy/composition strategy;
- typography character and roles;
- accent and semantic color strategy;
- surface/border/radius/shadow language;
- icon/image treatment;
- control/component expression;
- motion level;
- anti-patterns to avoid.

## Options
If direction is genuinely open, propose 2–3 clearly different directions. Do not offer three minor palette variants. Recommend one and explain why.

## Anti-generic test
Reject unjustified AI/SaaS defaults such as decorative gradient heroism, card-grid inflation, excessive pills, huge radii, arbitrary glass effects, and decorative charts.

## Gate
Select one direction before design-system definition or production implementation.
