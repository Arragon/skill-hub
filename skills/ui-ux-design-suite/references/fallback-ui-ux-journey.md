# Journey / Task Flow

## Procedure

For the target task define:

- entry points;
- prerequisites;
- primary happy path;
- decision points;
- back/cancel/escape behavior;
- recoverability;
- validation and failure paths;
- interrupted/resumed flow;
- permission/auth boundaries;
- feedback at meaningful state changes;
- completion and post-completion state.

Preserve existing product semantics and navigation unless a change is necessary and justified.

## Output
Use a compact numbered flow or state-flow representation. Mark unresolved material decisions explicitly.

## Gate
Do not decide colors, typography, or visual decoration here. Route grouping/navigation questions to IA and screen placement questions to wireframe.
