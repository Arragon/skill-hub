# Measure UX Outcomes

## Goal
Connect the design change to observable user outcomes without inventing false precision.

## Procedure

1. Restate the user/task outcome the design is supposed to improve.
2. Choose the smallest useful evidence:
   - task success/completion;
   - time/steps to complete;
   - error/retry rate;
   - abandonment at a specific step;
   - discoverability/usage of a function;
   - support complaints or qualitative usability evidence;
   - accessibility-specific completion barriers.
3. Define instrumentation only where the product can reasonably collect it.
4. For low-cost reversible uncertainty, prefer a small usability test/prototype test before building large analytics infrastructure.
5. For an A/B test, define the hypothesis, primary outcome, guardrails, and stopping/decision rule before looking at results.
6. Avoid vanity metrics and unsupported target percentages.

## Output
A short measurement plan: hypothesis, observable outcome, evidence source, and what result would change the design decision.
