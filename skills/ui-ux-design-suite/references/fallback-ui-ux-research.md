# UI/UX Research

Read `../../references/reference-research.md`.

## Procedure

1. Define the exact design uncertainty to research.
2. Search the current product evidence first.
3. When fresh external information can change the decision, use available web/research tools.
4. Prefer authoritative platform/design guidance for standards and behavior.
5. Use mature comparable products for interaction patterns.
6. Use real-user/community sources for pain points and workflow friction, not for hard specifications.
7. Select only references that map to the target task.

## Output
For each selected reference include:

- pattern;
- problem solved;
- why it transfers;
- important difference/constraint;
- what not to copy.

End with a small set of design implications, not a catalog.
