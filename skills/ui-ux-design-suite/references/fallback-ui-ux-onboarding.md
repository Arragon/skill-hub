# Onboarding / First Run

## Define activation first
State the first meaningful outcome the user should reach. Do not optimize onboarding completion as an end in itself.

## Procedure

1. Map entry state and prerequisites.
2. Explain value before asking for effort or permissions.
3. Ask only for setup information needed to reach activation.
4. Allow skip/escape where the product can remain useful without the step.
5. Use progressive guidance instead of front-loading instructions.
6. Design useful zero-data/empty states.
7. Handle setup failure, permission denial, interruption, retry, and returning users.
8. Avoid blocking experienced users with repeated tours.
9. Check keyboard, screen-reader, cognitive load, and motor accessibility concerns.

## Output
Activation goal + first-run journey + copy/state requirements + success/failure completion states.
