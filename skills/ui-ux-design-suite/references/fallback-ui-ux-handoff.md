# Handoff and Documentation

## What to persist
Persist only decisions future work should obey:

- durable product semantics or user-flow facts → PRODUCT.md/product docs;
- durable visual system, component behavior, tokens, density, navigation language, motion/accessibility invariants → DESIGN.md;
- one-off page details → task/PR notes, not global design rules.

## Handoff contents

- approved scope and outcome;
- key UX/design decisions;
- changed shared components/tokens and intended consumers;
- important states/responsive behavior;
- verification performed;
- remaining risks or deferred work.

## Principle
The next competent engineer/designer should be able to maintain the result without re-litigating settled decisions, but should not inherit unnecessary process history or temporary experiments.
